📋 Pour activer l'automatisation complète

Ces étapes se font une seule fois, en dehors de ce panel (sur Vercel) :

  1. Créer un compte MoreThanPanel et récupérer ta clé API
  2. Ajouter MTP_API_KEY comme variable d'environnement sur Vercel
  3. Faire correspondre chaque service de ton catalogue à son ID MoreThanPanel
  4. Redéployer le site

Une fois fait, chaque commande payée sera transmise automatiquement à MoreThanPanel — même la nuit, même hors ligne.
